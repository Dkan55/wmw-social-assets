# wmw-social-assets

Bilder und Videos fuer die Instagram und Facebook Beitraege von wirmachenweb.

Dieses Repo ist oeffentlich, weil Meta die Medien per cURL von einer
oeffentlichen URL abholt. Ein direkter Upload ist bei Bildern nicht moeglich.

Hier liegt ausschliesslich Material, das oeffentlich gezeigt werden darf.
Was hier landet, bleibt erreichbar, auch wenn der zugehoerige Beitrag
spaeter geloescht wird.
